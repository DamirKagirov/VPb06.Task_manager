# Telegram-бот «Командные задачи»

Простой бот для командной работы: участники добавляют задачи в общий список,
меняют их категории и статусы, смотрят список и выгружают его в CSV.

Написан на **Python**, **aiogram 3** и **SQLite** (через `aiosqlite`).

## Возможности

- `/start` — приветствие и главное меню.
- `/add текст` — добавить задачу одной строкой.
- `/add` — бот спросит текст задачи отдельным сообщением.
- `/list` — показать все задачи (с категорией, статусом, автором и датой).
- `/edit 3` — открыть карточку задачи и изменить категорию/статус кнопками.
- `/list_csv` — получить CSV-файл со всеми задачами.
- `/cancel` — отменить текущее действие.
- `/help` — краткая справка.
- Кнопки главного меню дублируют команды.

**Категории:** Стандартная (по умолчанию), Срочная.
**Статусы:** Новая (по умолчанию), В работе, Выполнена.

## Запуск

### 1. Получите токен бота

В Telegram напишите [@BotFather](https://t.me/BotFather):

1. `/newbot`
2. Придумайте имя и username бота.
3. Скопируйте токен вида `123456789:AA...`.

### 2. Установите зависимости

Нужен Python 3.10 или новее.

```bash
# создать виртуальное окружение
python -m venv venv

# активировать (Windows PowerShell)
venv\Scripts\Activate.ps1

# активировать (Windows cmd)
venv\Scripts\activate.bat

# активировать (Linux / macOS)
source venv/bin/activate

# установить зависимости
pip install -r requirements.txt
```

### 3. Создайте файл `.env`

Скопируйте `.env.example` в `.env` и укажите свой токен:

```env
BOT_TOKEN=123456789:AAExampleTokenReplaceMe
```

Файл `.env` уже добавлен в `.gitignore`, поэтому токен не попадёт в git.

### 4. Запустите бота

```bash
python main.py
```

В консоли появится `Бот запущен. Для остановки нажмите Ctrl+C.`
Теперь напишите боту `/start` в Telegram.

### Если появляется ошибка подключения к Telegram

Сообщение вида `TelegramNetworkError: Cannot connect to host api.telegram.org:443`
означает, что компьютер не может подключиться к серверам Telegram.
Код бота тут ни при чём — нужен рабочий доступ к `api.telegram.org`.

Что проверить:

1. Интернет и файрвол. Команда для проверки в PowerShell:

   ```powershell
   Test-NetConnection api.telegram.org -Port 443
   ```

   В конце должно быть `TcpTestSucceeded : True`.
2. Включите VPN и запустите бота снова.
3. Либо укажите прокси в `.env`:

   ```env
   # SOCKS5 (например, от локального VPN-клиента)
   PROXY_URL=socks5://127.0.0.1:1080

   # или HTTP-прокси
   PROXY_URL=http://user:password@proxy.example.com:8080
   ```

   Поддержка SOCKS уже входит в `requirements.txt` (пакет `aiohttp-socks`).

Если связи нет, бот больше не падает с трейсбеком: он пишет понятное
сообщение в консоль и повторяет попытку каждые 10 секунд. Можно включить
VPN уже после запуска — бот подключится сам.

## База данных

Файл базы: `data/tasks.db` (создаётся автоматически).
Таблица `tasks`:

```sql
CREATE TABLE IF NOT EXISTS tasks (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    text       TEXT NOT NULL,
    user       TEXT NOT NULL,
    created_at TEXT NOT NULL,
    category   TEXT NOT NULL DEFAULT 'Стандартная',
    status     TEXT NOT NULL DEFAULT 'Новая'
);
```

- `id` — номер задачи;
- `text` — текст задачи;
- `user` — кто добавил (имя и `@username`);
- `created_at` — дата и время добавления (локальное время сервера);
- `category` — категория (`Стандартная` или `Срочная`);
- `status` — статус (`Новая`, `В работе`, `Выполнена`).

Если база была создана старой версией бота (без `category` и `status`),
при запуске выполняется автоматическая миграция: колонки добавляются,
а существующие задачи получают значения по умолчанию. Данные не теряются.

Посмотреть содержимое базы можно, например, программой
[DB Browser for SQLite](https://sqlitebrowser.org/).

## CSV-файл

Файл называется `tasks_ГГГГ-ММ-ДД_ЧЧ-ММ.csv`, содержит колонки
`id, text, category, status, user, created_at` и сохраняется в кодировке
`utf-8-sig`, поэтому русский текст корректно открывается в Excel.

## Работа в группе

1. Добавьте бота в группу.
2. По умолчанию бот в группах видит только команды. Чтобы он реагировал
   на обычные сообщения (нужно для пошагового `/add`), откройте
   [@BotFather](https://t.me/BotFather) → `/setprivacy` → выберите бота →
   `Disable`, затем удалите бота из группы и добавьте снова.

Все участники группы работают с одной базой, поэтому список задач общий.

## Как это устроено (для новичков)

1. `main.py` создаёт `Bot` и `Dispatcher`, подключает роутеры и запускает
   `start_polling` — бесконечный цикл получения сообщений.
2. Каждый файл в `bot/handlers/` — отдельный `Router` со своими обработчиками.
3. В `bot/database/db.py` собраны все запросы к SQLite. Обработчики не пишут
   SQL сами, а вызывают `add_task()`, `get_tasks()` и т. д.
4. Для `/add` без текста используется FSM (`bot/states/task.py`): бот запоминает,
   что ждёт текст, и сохраняет следующее сообщение пользователя.
5. `/edit` показывает карточку задачи с inline-кнопками. Нажатие кнопки
   приходит в `callback_query`, обработчик обновляет строку в SQLite
   и перерисовывает карточку.
6. Состояния хранятся в памяти (`MemoryStorage`), после перезапуска бота
   незавершённые диалоги сбрасываются.
